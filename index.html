🏅 Mis medallas

🐣 ExploraSTEAM 3D

Un campus virtual inmersivo para estudiantes de primaria (6–11 años). Cada isla propone 5 misiones con el ciclo: ¿Sabías que…? → Experimenta (Laboratorio 3D o Minijuego) → Reto de 3 preguntas.

Computación gráfica en acción: L-Systems (árbol procedural), Morphing de mallas (esfera↔cubo), rasterización Bresenham, shaders GLSL (anillos de éxito con Fresnel + pulso), raycasting, sprites de etiquetas, iluminación Phong/Standard y render en tiempo real con WebGL + Three.js.

Stack: Three.js r128 · WebGL · GLSL · GSAP 3 · Web Speech API · Web Audio API · Vanilla JS
Equipo (2026-1 · Computación Gráfica y Visual): O. Martínez · C. Montalvo · J. Puican · J. Quispe · L. Sotelo · S. Yauri
